nano-pdf

Use it when
a page of a PDF, such as a slide, needs a quick change described in plain words, like a new title or a fixed typo
It does
runs the nano-pdf CLI with the file, a page number and your instruction
You get
an edited PDF, which the skill says to check before sending
Needs
the nano-pdf CLI, installable with uv, and a paid Gemini API key
Unlike
Anthropic's pdf skill, which merges, splits, fills and reads PDFs with code, it hands one edit to an AI image model

TLDR

A very short skill: it tells the agent to use the nano-pdf command-line tool to apply a natural-language edit to one page, as in nano-pdf edit deck.pdf 1 "Change the title to 'Q3 Results'". It warns that the tool counts pages from 0 or from 1 depending on its version, so an edit that lands on the wrong page should be retried with the other number, and that the output should be checked before it goes out. The rest is up to the tool. According to the tool's own page, it sends the page to Gemini 3 Pro Image, replaces it with the edited image, and adds the text back with OCR so it stays searchable, which is why it needs a paid Gemini key.

nano-pdf

Use nano-pdf to apply edits to a specific page in a PDF using a natural-language instruction.

Quick start

nano-pdf edit deck.pdf 1 "Change the title to 'Q3 Results' and fix the typo in the subtitle"

Notes:

  • Page numbers are 0-based or 1-based depending on the tool’s version/config; if the result looks off by one, retry with the other.
  • Always sanity-check the output PDF before sending it out.
