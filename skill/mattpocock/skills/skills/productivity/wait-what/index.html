TLDR

A one-line prompt to fire when an answer doesn't land. It tells the agent you're lost and asks it to explain that message again: a little context first, then the explanation in ASD-STE100 Simplified Technical English, a controlled English with short sentences and a limited vocabulary, made for aircraft manuals. It also asks the agent to use the terms defined in your repo's glossary, so the wording matches the rest of the project. It only re-explains the last message.
