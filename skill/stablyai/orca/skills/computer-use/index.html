computer-use

Use it when
a task needs a desktop app's or browser window's interface, and no command, file or API can do it
It does
clicks, types, opens menus, answers dialogs and takes screenshots in native apps and outside browser windows such as Chrome, Edge or Safari
Needs
Orca, Stably's desktop app for working with many coding agents in parallel, installed; it starts Orca if it isn't running
Unlike orca-cli
which drives the browser built into Orca, this works on other windows on your screen

TLDR

It gives an agent a way to work with apps that only have a graphical interface. Through the orca computer command, the agent reads a visible window as its accessibility tree, the structured list of buttons, fields and menus that screen readers use, then clicks, types, picks menu items, answers dialogs and takes screenshots. The SKILL.md itself is a short stub: it has the agent load the guide that matches the installed Orca version, so the instructions follow the app. It tells the agent to prefer the shell, files, git, HTTP or an existing CLI whenever one of those can do the job, and to reach for the interface only when nothing else can. It also guards against a Linux pitfall: outside Orca's own terminals, a bare orca command usually starts the GNOME screen reader of the same name.
