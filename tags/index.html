Flags flag:

Is there something to check before installing? any per skill.

TagSkillsMeaning
flag:republished11A copy of another publisher's skill under a different org. Each copy found had hundreds of thousands of installs while its original had fewer than twenty, so treat its ranking with caution.
flag:mirror0The same publisher ships the skill under two sources, which splits its counts.
flag:deprecated4The SKILL.md now says the skill is retired and points to a replacement.
flag:dual-use10Legitimate uses exist, but the same capability can evade bot detection or investigate other people. Read the SKILL.md before installing.
flag:tool-docs90Documentation for agents of one product: how to build with it, configure it, deploy to it or operate it, so it only helps once you use that product. A skill that gets a job done through a tool, such as browsing, testing, scraping, searching or generating media, doesn't count.
