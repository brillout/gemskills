TLDR

Its core is caveman, a mode that makes the agent lead with the answer in short plain sentences, with no greetings, hedging or recaps, until you say "stop caveman"; ultracave and megacave, two more skills in the repo, cut further. The other skills carry the idea beyond chat. caveman-commit writes Conventional Commits messages with a subject of 50 characters when possible, caveman-review writes one line per review finding, and caveman-compress rewrites a memory file such as CLAUDE.md in caveman style to save input tokens, backing up the original. cavecrew delegates searches, small edits and reviews to three subagents whose reports come back compressed, so the main context lasts longer. caveman-stats shows the session's recorded token usage, and caveman-help lists every mode and command. Five short skills are work patterns the agent picks up when a task fits: investigate-first diagnoses before editing, lean-build builds only what's asked, surgical-patch fixes at the narrowest layer, safe-refactor keeps behavior unchanged and migration keeps changes reversible. The repo also ships a CLI and a proxy that shrink what the agent reads; this bundle covers its skills.
