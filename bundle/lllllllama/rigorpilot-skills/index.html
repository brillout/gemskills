Use it when
you want an agent to run a deep learning research repo from its README and record honestly what worked

TLDR

The repo's main skill, ai-research-reproduction, runs a reproduction end to end. It isn't listed among these five, but the bundle's install command adds it with them. The five are its steps, and each can also be called on its own. repo-intake-and-plan reads the README and project files, sorts the documented commands into inference, evaluation and training, and picks the smallest one worth trusting. paper-context-resolver steps in only when the README leaves out a detail that matters, such as which dataset split to evaluate on, and looks it up in the paper, noting any conflict. env-and-assets-bootstrap drafts conda commands and where checkpoints and datasets should go, before anything runs. minimal-run-and-audit runs the chosen command and writes the evidence to repro_outputs/, including any patch and any change to data, evaluation or metrics; its scripts need the main skill. ai-research-explore, which needs it too, is a separate lane: only when you ask, and starting from a model or run you already have, it ranks and tries new research ideas, writes them to explore_outputs/, and never reports them as reproduced results.

Its skills, in the order they're used

The ones marked “Only in the bundle” need the rest of it, so they're only listed here. The others also have their own entry in the skills list.

  1. repo-intake-and-plan

    450K installs

    Maps a deep-learning repo and plans a README-first reproduction.

  2. paper-context-resolver

    451K installs

    Fills the gaps a README leaves when reproducing a deep-learning paper's repo.

  3. env-and-assets-bootstrap

    450K installs

    Prepares a conda environment, datasets and checkpoints for a reproduction.

  4. minimal-run-and-audit

    Only in the bundle 450K installs

    Runs a minimal reproduction and records the evidence.

    Its run and report scripts load a shared runtime that ships inside ai-research-reproduction, the repo's main skill, and stop with an error without it.

  5. ai-research-explore

    Only in the bundle 311K installs

    Explores novel research candidates on top of a reproduced baseline.

    Loads its required research loop and shared runtime from ai-research-reproduction, the repo's main skill, and hands code changes and trial runs to the repo's explore-code and explore-run skills.
